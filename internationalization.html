    Each text has a key consisting of nested names: [ACCUEIL.BONJOUR]. These are the same dictionaries as in previous lessons, with two specific features of [i18next]:

    • parameters are written as [{{nom}}]; a parameter can be formatted according to the language: [{{date, datetime(dateStyle: full)}}] (a date, with the options from [Intl.DateTimeFormat]), [{{prix, currency(EUR)}}] (an amount in euros);
    • plurals: [i18next] automatically selects the form based on the parameter [count] and the language rules: [RENDEZ_VOUS_one] or [RENDEZ_VOUS_other], and [RENDEZ_VOUS_zero] for zero, if it exists. Polish, Arabic, and other languages have different forms ([_few], [_many]), which [i18next] recognizes.

    // =========================================================================
// 21-i18n/src/i18n/i18n.ts - i18next configuration
// -------------------------------------------------------------------------
// i18next is the most widely used translation library in JavaScript;
// react-i18next connects it to React. It is provided with:
//    - a DICTIONNAIRE per language (fr.json, en.json), where each text has a
//      CLÉ ("ACCUEIL.BONJOUR"); parameters are written as {{name}};
//      {{date, datetime(...)}} and {{price, currency(EUR)}} format
//      a date or an amount depending on the language (using API Intl);
//    - the source language (the one stored in localStorage, otherwise the
//      of the browser, otherwise French) and the fallback language.
// In a component, t('ACCUEIL.BONJOUR', { name: 'Marie' }) returns the text
// in the COURANTE language; changing the language reloads the components that
// use t, and the entire page is re-translated.
//
// On the client side, this follows the same principle as the NestJS course (dictionaries
// i18n/*.json + {{t}} helper) — but the translation now takes place within
// the browser, and switching languages no longer requires any server interaction.
// =========================================================================

import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import fr from './fr.json';
import en from './en.json';

export type Langue = 'fr' | 'en';
export const LANGUES: Langue[] = ['fr', 'en'];
const CLE_LANGUE = 'exemple21.langue';

function langueDeDepart(): Langue {
  const memorisee = localStorage.getItem(CLE_LANGUE);
  if (memorisee === 'fr' || memorisee === 'en') {
    return memorisee;
  }
  return navigator.language.startsWith('en') ? 'en' : 'fr';
}

// every time the language changes: it is stored, and
// the page’s lang attribute (useful for screen readers and proofreaders)
i18n.on('languageChanged', (langue) => {
  localStorage.setItem(CLE_LANGUE, langue);
  document.documentElement.lang = langue;
});

// use(initReactI18next): i18next notifies React of language changes
i18n.use(initReactI18next).init({
   // Dictionaries are part of the application code: no requests
  resources: { fr: { translation: fr }, en: { translation: en } },
  lng: langueDeDepart(),
  fallbackLng: 'fr', // A key is missing in English: we use the French version
   // React already escapes everything it displays: i18next doesn’t need to do it
  interpolation: { escapeValue: false },
});

export default i18n;
    • lines 23–24: the dictionaries are part of the application code: they are JSON modules, imported as objects ([resolveJsonModule], see [tsconfig.json]);
    • lines 30–36: the source language: the one stored in [localStorage], otherwise the browser’s language, otherwise French;
    • lines 40–43: each time the language changes, it is stored and the page’s [lang] attribute is updated (useful for screen readers and spell-checkers);
    • lines 46–53: configuration: the dictionaries ([translation] is the name of the default key space), the source language, the fallback language (if a key is missing in English, French is used), and [escapeValue: false]: [React] already escapes everything it displays.

    // =========================================================================
// 21-i18n/src/App.tsx - a translated page
// -------------------------------------------------------------------------
//    - const { t, i18n } = useTranslation() : the translation function, and
//      the i18next object (i18n.language: the current language);
//    - t('CLE'                       ) a text string;
//    - t('CLE', { name: ...          }) text with parameters;
//    - t('CLE', { count: n }         ) plural text: i18next selects
//                                      the key CLE_zero, CLE_one, or CLE_other;
//    - i18n.changeLanguage('en'      ) changes the language: the entire page is
//                                      is re-translated.
// =========================================================================

import { useEffect, useState } from 'react';
import { useTranslation } from 'react-i18next';
import { LANGUES } from './i18n/i18n';

// what the server would return: RdvMedecins (see the chapter on the black box)
const REPONSES_SERVEUR = [
  { statusCode: 409, cle: 'ERRORS.LOGIN_TAKEN', params: {} },
  { statusCode: 429, cle: 'ERRORS.TOO_MANY_ATTEMPTS', params: { minutes: '15' } },
];

export default function App() {
  const { t, i18n } = useTranslation();
  const [nombre, setNombre] = useState(2);
  const [aujourdhui] = useState(() => new Date());

   // the tab title follows the language
  useEffect(() => {
    document.title = t('APP.TITRE');
  }, [t]);

  return (
    <div className="container py-4" style={{ maxWidth: 720 }}>
      <div className="d-flex justify-content-between align-items-center mb-3">
        <h1 className="h3 mb-0">{t('APP.TITRE')}</h1>
        <div className="btn-group btn-group-sm" role="group" aria-label={t('APP.LANGUE')}>
          {LANGUES.map((l) => (
            <button key={l} className={`btn ${i18n.language === l ? 'btn-primary' : 'btn-outline-primary'}`}
                    onClick={() => i18n.changeLanguage(l)}>
              {l.toUpperCase()}
            </button>
          ))}
        </div>
      </div>

      <div className="card p-3 mb-3">
        <p>{t('ACCUEIL.BONJOUR', { nom: 'Marie' })}</p>
        {/* the date and amount are formatted by the dictionary in the current language */}
        <p>{t('ACCUEIL.AUJOURDHUI', { date: aujourdhui })}</p>
        <p>{t('ACCUEIL.PRIX', { prix: 1234.5 })}</p>
        {/* count: selects the plural form and replaces {{count}} */}
        <p className="fw-bold">{t('ACCUEIL.RENDEZ_VOUS', { count: nombre })}</p>
        <div className="d-flex gap-2">
          <button className="btn btn-sm btn-outline-success" onClick={() => setNombre(nombre + 1)}>{t('ACCUEIL.AJOUTER')}</button>
          <button className="btn btn-sm btn-outline-secondary" disabled={nombre === 0} onClick={() => setNombre(nombre - 1)}>
            {t('ACCUEIL.RETIRER')}
          </button>
        </div>
      </div>

      <div className="card p-3">
        <h2 className="h6">{t('SERVEUR.TITRE')}</h2>
        <p>{t('SERVEUR.EXPLICATION')}</p>
        <ul className="mb-0">
          {REPONSES_SERVEUR.map((r) => (
             // the server key EST a dictionary key; params provides its parameters
            <li key={r.cle}>
              <code>{r.statusCode} {r.cle}</code>
              <br />&rarr; {t(r.cle, r.params)}
            </li>
          ))}
        </ul>
      </div>
    </div>
  );
}
    • Line 25: the hook for [react-i18next]: [t], the translation function, and [i18n], the [i18next] object ([i18n.language] is the current language). The component is called when the language changes;
    • lines 30–32: the tab title follows the language: the function [t] changes with the language;
    • line 41: change language: the entire page is re-translated without making any requests to the server;
    • line 49: text with parameters;
    • lines 51–52: a date and an amount, formatted by the dictionary in the current language;
    • line 54: a plural form;
    • line 71: the key sent by the server [RdvMedecins] EST a key from the dictionary (see next chapter); [params] provides its parameters.
